# Fable for Science Skill
[English](README_en.md)

**研究 → 结构 → 寓言**

受《三体》的云天明故事启发，Fable4Sci 是一个将复杂科学与技术内容转换成寓言的 Agent Skill，同时尽可能保留原问题的核心结构。

它并不是简单地把科学术语替换成比喻，而是先提取问题中的关键结构，例如实体、关系、约束、证据、不确定性、权衡以及失败模式，再把这些结构重新映射到一个新的故事世界中。

它的核心原则很简单：

> **改变表达形式，保留推理结构。**

## 它能做什么

输入一个研究问题、方法、结果或技术概念后，Fable4Sci 可以生成：

* **简明寓言（Plain Fable）** —— 简洁、易理解的结构化转换
* **意象寓言（Image-Rich Fable）** —— 更具叙事性和想象力的版本
* **保真检查（Fidelity Check）** —— 简要检查原始科学结构是否得到保留

它可以用于科学传播、教学、概念探索，以及从不同视角重新理解熟悉的研究问题。

## 使用方法

将 [`SKILL.md`](./SKILL.md) 作为 Agent 的 instruction skill 使用，然后提供你希望转换的科学内容即可。
